4. Visualizar y probar la página en el navegador

Guardar y abrir los archivos

Guarda todos los archivos (Ctrl + S) dentro de la misma carpeta del proyecto, respetando las subcarpetas css, js e img. Para ver la página basta con abrir index.html con doble clic: se abrirá en el navegador predeterminado.

Usar Live Server en Visual Studio Code

La extensión Live Server abre la página en un servidor local y la recarga automáticamente cada vez que guardas un cambio. Instálala desde la pestaña Extensiones de Visual Studio Code, haz clic derecho sobre index.html y elige Open with Live Server, o pulsa Go Live en la barra inferior.

Verificar que todo funciona

Enlaces: haz clic en cada elemento de la lista y en los botones Anterior, Siguiente y Volver al tutorial; todos deben abrir la página correcta. CSS: si ves colores, tipografía y espaciado, la hoja de estilos cargó; si la página aparece en blanco y negro, revisa la ruta del <link>. JavaScript: en el tema 3 pulsa “Probar JavaScript” y comprueba que el mensaje cambia. Con F12 puedes abrir la consola del navegador y verificar que no hay errores.

Procedimiento de prueba

  1. Abrir la carpeta en Visual Studio Code.
  2. Abrir index.html.
  3. Ejecutar con Live Server.
  4. Navegar por los temas.
  5. Comprobar estilos y JavaScript.
