2. Aplicar estilos con CSS

¿Qué es CSS?

CSS (Cascading Style Sheets, hojas de estilo en cascada) es el lenguaje que define la apariencia de una página web. Mientras HTML dice qué es cada elemento, CSS dice cómo se ve.

¿Para qué sirve?

Con CSS se controlan los colores del texto y de los elementos, la tipografía (fuente, grosor y tamaño de letra), los tamaños de cajas e imágenes, los márgenes y espacios internos (margin y padding), los fondos y la distribución de los elementos en pantalla con herramientas como Flexbox o Grid. Además, con las media queries la página se adapta a computadores, tabletas y celulares.

Lo recomendable es escribir los estilos en un archivo externo (por ejemplo css/estilos.css) y enlazarlo desde cada página con la etiqueta <link>.

Ejemplo de CSS

body {
    font-family: Arial, sans-serif;
    background-color: #F6F7F9;
    color: #333333;
    margin: 0;
}

h1 {
    color: #0F1F3D;
    font-size: 2rem;
}

.boton {
    background-color: #0F1F3D;
    color: #FFFFFF;
    padding: 12px 20px;
    border-radius: 8px;
}
