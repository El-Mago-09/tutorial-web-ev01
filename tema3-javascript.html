3. Agregar interactividad con JavaScript

¿Qué es JavaScript?

JavaScript es un lenguaje de programación que se ejecuta en el navegador. Permite que la página deje de ser solo contenido estático y responda a lo que hace la persona usuaria.

¿Para qué se utiliza?

Se usa para mostrar u ocultar elementos, validar formularios, cambiar textos e imágenes, crear menús, cargar datos y, en general, reaccionar a las acciones del usuario.

Eventos básicos

Un evento es algo que ocurre en la página: un clic (click), escribir en un campo (input), pasar el ratón por encima (mouseover) o terminar de cargar la página (DOMContentLoaded). Con addEventListener le decimos al navegador qué función ejecutar cuando ocurra ese evento:

const boton = document.getElementById("boton-probar");
const mensaje = document.getElementById("mensaje-js");

boton.addEventListener("click", function () {
    mensaje.textContent = "¡JavaScript está funcionando correctamente!";
});
